# 🌌 Misión Enteros | Reactor Matemático

¡Bienvenido a **Misión Enteros**, un videojuego educativo e interactivo ambientado en el espacio exterior! Este proyecto está diseñado para que los estudiantes refuercen sus habilidades matemáticas mediante la resolución de problemas lógicos y algebraicos en un entorno dinámico y gamificado.

Actividad realizada por: **Lina Maria Acosta Guarnizo**.

---

## 🚀 Características del Proyecto

*   **🎮 Modo Arcade (Cazador de Respuestas):** Mecánica de juego tipo *shooter* espacial donde el usuario mueve una nave para disparar al asteroide que contiene la respuesta correcta.
*   **🗺️ Mapa de la Misión (5 Destinos):** progresión por niveles interactivos:
    *   🌍 *Nivel 1:* Números Enteros.
    *   🌑 *Nivel 2:* Problemas Matemáticos.
    *   🛰️ *Nivel 3:* Álgebra Basica.
    *   🪐 *Nivel 4:* Factor Común.
    *   🌌 *Nivel 5:* Agrupación.
*   **🧠 Banco de Ejercicios:** Más de 100 ejercicios integrados con generación de hasta 20 retos por misión.
*   **🌙 Interfaz Adaptable:** Incluye soporte para modo nocturno y una galaxia en colores neón altamente atractiva.
*   **📊 Sistema de Estadísticas:** Puntuación en tiempo real, contador de retos resueltos y racha de aciertos.

---

## 🕹️ Controles del Juego

El juego está optimizado tanto para computadores como para dispositivos móviles:

| Dispositivo | Movimiento | Acción (Disparar/Reparar) |
| :--- | :--- | :--- |
| **💻 Computador** | Flechas Izquierda / Derecha (`←` `→`) | Barra Espaciadora (`Space`) |
| **📱 Celular / Tablet** | Botones táctiles de flechas en pantalla | Botón táctil **DISPARAR / REPARAR** |
